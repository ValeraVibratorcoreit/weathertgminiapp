# Веб-приложение прогноза погоды для Telegram

Веб-приложение для Telegram, отображающее прогноз погоды с использованием API OpenWeatherMap.

## Возможности
- Текущая погода (температура, влажность, ветер, УФ-индекс, давление)
- Прогноз на 3 и 10 дней
- Время восхода/заката и продолжительность светового дня
- Фаза луны и состояние магнитного поля
- Динамический фон в зависимости от погоды и времени суток
- Адаптивный дизайн с темной темой
- Поддержка геолокации
- Интерфейс на русском языке

## Технологии
- HTML, CSS, JavaScript
- Telegram Web App SDK
- API OpenWeatherMap
- Шрифт Inter (Google Fonts)

## Установка
1. Клонируйте репозиторий:
   ```bash
   git clone <repository-url>
   ```
2. Замените `'yours'` в скрипте на ваш API-ключ OpenWeatherMap:
   ```javascript
   const apiKey = 'ваш-api-ключ';
   ```
3. Разместите файлы на веб-сервере или используйте локальный сервер (например, Live Server в VS Code).
4. Откройте приложение в Telegram через ссылку бота или кнопку Web App.

## Использование
- Нажмите "Поделиться местоположением" для доступа к геолокации.
- Просматривайте текущую погоду, прогноз на 3 и 10 дней, информацию о световом дне.
- Переключайтесь между вкладками "Подробный прогноз" и "На месяц" (прогноз на месяц требует премиум-версии).

## Примечания
- Требуется действительный API-ключ OpenWeatherMap.
- Геолокация должна быть включена в браузере.
- Вкладка прогноза на месяц отображает заглушку для премиум-функций.
- Совместимо с современными браузерами, поддерживающими геолокацию и fetch API.
